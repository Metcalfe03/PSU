Beginner Lesson

Compatibility 101

The “will these parts work together?” tips.

Research twice, buy once.

Compatibility at a Glance

Quick reference table
Summary
Component Must Match With Why It Matters
CPU Motherboard Socket Physical and electrical compatibility
RAM DDR4 / DDR5 Wrong generation will not fit
Storage SATA / NVMe Slot Board must support the drive type
GPU Case Clearance + PCIe Slot Large cards may not physically fit
PSU Total System Wattage Insufficient power causes instability

1) CPU ↔ Motherboard

Socket + chipset support
“The big one”

Your CPU must match the motherboard’s socket. If the socket doesn’t match, it won’t fit. Even with a matching socket, some boards need a BIOS update to support newer CPU generations.

Simple takeaway: Pick a CPU, then choose a board that explicitly supports it.
Must match
CPU socket
Common gotcha
BIOS support
Beginner tip
check CPU support list

2) RAM ↔ Motherboard

DDR type + slots
“Fits or doesn’t”

RAM must match the board’s RAM type (example: DDR4 vs DDR5). The wrong type won’t even physically fit. Capacity and speed matter too, but type is the hard compatibility rule.

Simple takeaway: DDR4 and DDR5 are not interchangeable, they should match the board.
Must match
DDR4 or DDR5
Common gotcha
mixing different kits
Beginner tip
buy a 2-stick kit

3) Storage ↔ Motherboard

SATA vs M.2 (NVMe)
“Slot rules”

Storage compatibility is mostly interface. SATA drives use cables. M.2 drives use motherboard slots. Some M.2 slots support NVMe, some support SATA, and some support both. Your motherboard’s specs tell you which is which.

Simple takeaway: Make sure your board has the right slot for the drive you’re buying.
Must match
SATA vs NVMe
Common gotcha
M.2 slot limitations
Beginner tip
start with 1 NVMe SSD

4) GPU ↔ Fit + Slot

Case clearance + PCIe slot
“Physical check”

Most GPUs work in the main PCIe slot on modern boards. The real compatibility problems are physical: GPU length, thickness, and whether it blocks other slots or cables in tight cases.

Simple takeaway: Going small needs extra care + measuring.
Must match
case GPU clearance
Also check
PCIe slot position
Beginner tip
measure before buying

5) PSU ↔ Power Cables

Wattage + connectors
“Stability”

PSU compatibility is about having the right cables for your motherboard and GPU, plus enough wattage. The motherboard needs the 24-pin and CPU power. GPUs may need one or more PCIe power connectors.

Simple takeaway: Don’t buy “more watts” only. Make sure your wattage matches your GPU + CPU needs.
Must match
GPU power connectors
Common gotcha
missing PCIe cables
Beginner tip
leave upgrade headroom

6) Case ↔ Size

Motherboard + cooler fit
“Does it fit?”

Cases support certain motherboard sizes (ATX, mATX, ITX). They also limit GPU length and CPU cooler height. A case can be “compatible” in theory but still feel cramped if it’s too small.

Simple takeaway: Match case size to motherboard, then verify GPU + cooler clearance.
Must match
ATX/mATX/ITX support
Also check
cooler + GPU clearance
Beginner tip
airflow > looks

7) Cooling ↔ Mounting

Socket bracket + clearance
“Mount fit”

Your CPU cooler must support your CPU socket (mounting bracket). It also has to physically fit in the case. Big air coolers can hit RAM or side panels. Liquid coolers need radiator support.

Simple takeaway: Socket support + case clearance are the two checks.
Must match
socket mounting bracket
Also check
case clearance / radiator
Beginner tip
air cooling is enough

8) OS + Drivers

Software compatibility
“Support”

Most hardware works on modern Windows with minimal effort. Linux is great too, but some games need software workarounds and specialty tools may need extra setup.

Simple takeaway: Pick the OS based on the apps and games you actually use.
Must match
your software needs
Common gotcha
GPU drivers (Nvidia = Simple)
Beginner tip
Windows is simplest

9) Ports + Peripherals

Monitor, USB, audio
“I/O”

Compatibility here is simple: do you have the ports you need? Make sure your monitor connections match your GPU outputs, and that you have enough USB ports for your devices.

Simple takeaway: A strong PC can feel bad if the monitor doesn’t match it.
Must match
monitor ↔ GPU output
Also check
USB ports, audio needs
Beginner tip
prioritize the monitor
