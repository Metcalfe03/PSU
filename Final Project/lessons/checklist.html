Beginner Lesson

Build Checklist

A calm, step-by-step checklist so nothing gets missed.

The “read this before you start” checklist.

Before You Start

Prep your space
“Setup”

Give yourself room to work. A clean table, good light, and a small tray for screws makes the whole build less stressful.

Simple takeaway: A calm setup prevents dumb mistakes.
You want
clear table + good light
Have ready
#2 Phillips screwdriver
Beginner tip
keep screws grouped

Confirm Your Parts

The quick “compatibility sanity check”
“Verify”

Double-check the key matches before anything goes into the case: CPU ↔ motherboard socket, RAM type (DDR4/DDR5), and storage type (M.2 vs SATA).

Simple takeaway: Verify first, build second.
Must match
CPU socket
Must match
RAM DDR type
Must match
storage slot type

Build on the Motherboard First

CPU, RAM, and SSD outside the case
“Easier”

Install the CPU, RAM, and M.2 SSD on the motherboard before putting the board in the case. It’s easier, you can see everything, and you’re less likely to force something.

Simple takeaway: Do CPU + RAM + NVMe (M.2) SSD first, it keeps it simple.
Order
CPU → RAM → M.2 SSD
Common gotcha
RAM not fully clicked
Beginner tip
don’t force anything

Install the CPU Cooler

Mount + plug the fan
“Temps”

Install the cooler according to its instructions. Make sure the fan cable is plugged into the motherboard header labeled CPU_FAN.

Simple takeaway: CPU fan must be plugged into CPU_FAN.
Don’t miss
remove plastic film, applying thermal paste
Plug into
CPU_FAN header
Beginner tip
even pressure on screws

Prep the Case

Standoffs + airflow plan
“Fit”

Check that motherboard standoffs match your board size. Plan your airflow: front/side intake, rear/top exhaust. You don’t need a perfect setup, just a sensible one.

Simple takeaway: Standoffs must match your motherboard, or you risk damage.
Check
standoff positions
Airflow
intake front, exhaust top/rear
Beginner tip
more intake is fine

Install the PSU

Mount + route the main cables
“Power”

Install the PSU and route the big cables first: 24-pin motherboard power and CPU 8-pin power. This makes the rest of the build cleaner.

Simple takeaway: Don’t forget the CPU 8-pin power, it’s an easy miss.
Must plug in
24-pin + CPU 8-pin
Common gotcha
wrong CPU cable
Beginner tip
route behind the tray

Install the GPU

Slot + power cables
“Click”

Put the GPU in the top PCIe slot (usually). Make sure it fully clicks in, then connect the GPU power cables from the PSU.

Simple takeaway: If the GPU isn’t fully seated, the PC often won’t display anything.
Install in
top PCIe slot
Also check
power connectors
Beginner tip
use the case screws

Front Panel + USB

The “tiny cable” phase
“Annoying”

Connect the case front panel (power button, reset, LEDs), front USB, and front audio. This is the fiddliest step. Try to go slow and use the motherboard manual when necessary.

Simple takeaway: The motherboard manual is your best friend here.
Use
motherboard manual diagram
Common gotcha
power switch pins
Beginner tip
do it in good light

First Boot

POST + BIOS check
“Moment of truth”

Power on and look for the first sign of life: fans spin, lights turn on, and you get a display signal. If it boots into BIOS, you’re winning.

Simple takeaway: No display? Check monitor cable is plugged into the GPU.
Good signs
BIOS screen appears
Common gotcha
monitor plugged into motherboard
Beginner tip
check RAM seating first

OS + Drivers

Install, update, breathe
“Finish”

Install your operating system, then install GPU drivers and run updates. Once drivers are in, performance and stability improve a lot.

Simple takeaway: Install GPU drivers early, it forgetting to do this and wondering why performance is poor is a common mistake, even for experienced builders.
Install
OS first
Then
GPU + chipset drivers
Beginner tip
update BIOS later
